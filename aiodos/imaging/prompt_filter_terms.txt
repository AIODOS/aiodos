# Les termes du filtre des descriptions envoyées au réseau public (imaging/prompt_filter.py ;
# décision de l'auteur du 29/10/2026). Lu une fois, au premier usage du filtre.
#
# Format : « [classe] », puis des termes séparés par des virgules, sur autant de lignes qu'on
# veut ; « # » commence un commentaire. On écrit les termes naturellement : la casse, les
# accents et les ligatures sont ramenés comme dans les descriptions, et un tréma vaut aussi
# sa forme en « e » (« Mädchen » : « madchen » et « maedchen »). Un groupe entre parenthèses
# est facultatif : « enfant(s) » vaut « enfant » et « enfants » ; « adolescent(e)(s) », quatre
# formes. Un terme de plusieurs mots se reconnaît aussi collé (« petitefille ») ou coupé par
# des signes (« petite-fille »). Un terme écrit sans espaces (chinois, japonais) se cherche
# n'importe où dans le texte.
#
# La règle (le détail : imaging/prompt_filter.py, au début) :
# - minor (ou un âge de moins de 18 ans, que le filtre lit lui-même), avec sexual :
#   minor_sexual ; ambiguous avec youth vaut minor ;
# - bridge compte comme minor à côté de sexual, et comme sexual à côté de minor ; seul, rien ;
# - real, ou possessive suivi de relation (« ma voisine », « my ex »), avec sexual :
#   real_person_intimate ;
# - coercion avec sexual : sexual_violence ;
# - forbidden_<code> : interdit seul, quel que soit le reste ;
# - dans la consigne négative (ce que l'image doit éviter) : clothing, avec minor dans la
#   description, ou adult, avec sexual dans la description, poussent vers un mineur dénudé :
#   minor_sexual ;
# - neutral : des expressions sans rapport (« pieds nus », « à l'œil nu »), ôtées d'abord ;
# - glue, stopwords, numbers : pour lire les mots collés, les mots coupés et les âges.
#
# Langues : français, anglais, espagnol, allemand, italien, portugais ; quelques termes
# chinois et japonais. Un mot à plusieurs sens (« kind » en anglais, « mineur » de la mine,
# « sexe » au sens du genre, « pelada » le match de foot au Brésil) n'est pris que dans une
# expression sans ambiguïté, ou pas du tout : avant d'ajouter un terme, cherche ses autres
# sens, dans les six langues (un mot est cherché dans toutes). Les descriptions ordinaires
# des essais (tests/test_prompt_filter.py) doivent toutes passer.
